# todo-react-avancado

Lista de tarefas com React avançado: Context API, hook customizado e memoization.

## Tecnologias
- React + Vite
- Context API / useContext
- useState, useEffect, useMemo, React.memo
- Hook customizado useLocalStorage
- CSS Mobile First

## Como rodar
git clone https://github.com/SEU-USUARIO/todo-react-avancado.git
cd todo-react-avancado
npm install
npm run dev
